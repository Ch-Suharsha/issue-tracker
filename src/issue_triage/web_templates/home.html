AI-assisted workflow · Triage, not resolution

Structured triage for messy GitHub issues

This app turns incoming issue title and body into a classified proposal — category, urgency, owner, and next action — then runs deterministic policy rules, gates high-impact paths behind human approval, and records dry-run actions only. Built to show how an embedded maintainer team can triage consistently without auto-writing to production.

  • 1 · Classify Jev (TypeSafe) reads the issue and proposes structure with confidence scores.
  • 2 · Policy Python rules override the model when stakes are high — e.g. SEC-001 on vulnerability language, EMPTY-001 on missing body.
  • 3 · Approve Triagers review, edit, approve or reject. Low-risk paths can auto-proceed; escalate and p1 always wait for a human.
