# V1 stack without LangGraph

Eval corpus is elastic/kibana with agreed filters and dual eval sets. V1 is Python, FastAPI, Neon Postgres, Jinja/HTMX on Render, with a single structured LLM call per Issue plus deterministic policy and workflow code — no LangGraph. Discovery brief uses fictional scale of about six maintainers and 100–150 issues per week, clearly labeled as fiction.
