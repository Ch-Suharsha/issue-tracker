# issue-tracker

AI-assisted GitHub issue triage workflow (FDE portfolio project).

Product work and agent tickets live in **local markdown** under `.scratch/` — see `docs/agents/issue-tracker.md`. This GitHub repo is for code and portfolio hosting.

Project decisions and audit notes: [`handout.md`](./handout.md).

## Agent skills

### Issue tracker

Local markdown under `.scratch/` (not GitHub Issues). See `docs/agents/issue-tracker.md`.

### Triage labels

Default roles: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout (`CONTEXT.md` + `docs/adr/` when they exist). See `docs/agents/domain.md`.
